# Pet Parent Assistant

A simple one-page landing page for an AI-powered pet care app. Built with plain HTML and CSS.

## Files
- `index.html` – page content
- `styles.css` – all styling

## Preview locally
Double-click `index.html`, or run `python3 -m http.server 8000` in this folder and open http://localhost:8000.
